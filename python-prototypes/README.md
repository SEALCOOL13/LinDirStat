# Python prototypes

These are the earlier Python/GTK3 and Python/PyQt5 versions of the app, kept for reference.
The Rust version in the repository root is the one to use: it is much faster and has every
feature these have plus the size-unit options.

* `windirstat_gtk.py`  – GTK3 version (needs `python3-gi gir1.2-gtk-3.0 python3-numpy`)
* `windirstat_linux.py` – PyQt5 version (needs `python3-pyqt5 python3-numpy`)
